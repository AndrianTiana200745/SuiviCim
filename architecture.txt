DESCRIPTION GÉNÉRALE:
════════════════════

📦 FRONTEND (React + Vite + Tailwind CSS)
   • Framework: React 19.2.0
   • Bundler: Vite 7.2.4
   • Styling: Tailwind CSS 4.1.18
   • Linter: ESLint 9.39.1
   • Formatter: Prettier
   • Router: React Router v7.13.0
   • Build: `npm run build` → dossier dist/
   • Dev: `npm run dev` → serveur HMR local
   • Lint: `npm run lint` → vérifier le code

STACK TECHNOLOGIQUE:
═══════════════════
✅ React 19.2.0 avec hooks
✅ React Router DOM pour la navigation
✅ Tailwind CSS pour le styling utility-first
✅ Vite pour le bundling & HMR
✅ PostCSS + @tailwindcss/postcss

STRUCTURE LOGIQUE:
══════════════════

1️⃣  Configuration Layer
    └─ vite.config.js, eslint.config.js, tailwind.config.js, postcss.config.js

2️⃣  Entry Point
    └─ src/app/ → main.jsx + App.jsx (routing)

3️⃣  UI Layer (Design System)
    ├─ components/ui/ → Composants réutilisables (Button, Input, Select, Textarea, FormGroup)
    ├─ components/layout/ → Composants de mise en page
    └─ assets/styles/ → Feuilles CSS globales (Tailwind reset)

4️⃣  Business Logic
    ├─ services/ → Appels API (à développer)
    ├─ hooks/ → Logique partagée (à développer)
    └─ utils/ → Fonctions utilitaires (à développer)

5️⃣  State Management
    └─ store/ → État global (à implémenter)

6️⃣  Features (Modules métier)
    ├─ auth/ → Authentification & connexion
    ├─ data-entry/ → Saisie de nouvelles données
    ├─ modification/ → Modification de données existantes
    └─ suppression/ → Suppression de données

7️⃣  Static Resources
    └─ public/ → Fichiers accessibles directement (favicon, etc.)

ROUTES ACTUELLES:
═════════════════
/              → ConnectionForm (page de connexion avec logo animé)
/dashboard     → Dashboard (tableau de bord avec statistiques et actions)
/saisie        → DataEntryForm (saisie des données)
/modification  → ModificationForm (modification des données)
/suppression   → DeleteDataForm (suppression des données)

COMPOSANTS UI DISPONIBLES:
════════════════════════════
📌 Button         - Bouton avec variants (primary, secondary, outline) + loader spinner
📌 Input          - Champ texte réutilisable avec validation
📌 Select         - Dropdown avec gestion d'erreurs
📌 Textarea       - Zone de texte multiligne
📌 FormGroup      - Conteneur grid pour grouper des inputs (2 colonnes par défaut)

COMPOSANTS DASHBOARD:
═════════════════════
📊 Dashboard          - Conteneur principal avec layout sidebar + content
📊 DashboardHeader    - En-tête sticky avec logo, profil utilisateur, notifications
📊 DashboardSidebar   - Menu latéral avec navigation responsive (mobile overlay)
📊 DashboardStats     - 4 cartes KPI (véhicules, modifications, suppressions, en attente)
📊 DashboardCards     - 4 cartes d'actions rapides vers les modules

STYLING:
═══════
• Tailwind CSS pour tous les styles (utility-first)
• Classes prédéfinies dans les composants UI
• Breakpoint responsive: md: (768px)
• Coloration: blue (primary), gray (secondary), red (danger)

ANIMATIONS IMPLÉMENTÉES:
═══════════════════════
🎬 Logo Rotating    - Rotation 3D du logo avec apparition (0.8s)

FLUX DE CONNEXION:
══════════════════
1. Utilisateur accède à "/" (ConnectionForm)
2. Remplissage du formulaire (identifiant, mot de passe, centre)
3. Clique sur "Se connecter"
4. Overlay fullscreen avec spinner circulaire (1.5s)
5. Redirection vers "/dashboard"
6. Affichage du tableau de bord avec animations
